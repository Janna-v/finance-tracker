# Finance Tracker

## Version 1

### Goal
Track income and expenses.

### Stack
- React
- TypeScript
- FastAPI
- SQLite
- SQLAlchemy

### Features
- Add transaction
- Delete transaction
- Transaction list
- Summary dashboard

### Dashboard
- Total income
- Total expenses
- Balance

### Transaction Model

- id
- date
- amount
- description (optional)
- type

### Not included in V1

- Authentication
- Users
- Categories
- Contacts
- Invoices
- Docker
- MySQL
